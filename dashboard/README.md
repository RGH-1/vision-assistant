# dashboard/ — React dashboard (M1)

React + Vite + TypeScript (strict) + Tailwind. Panels: Live (WHEP), Status, Timeline + search by meaning, Q&A, Alerts, Controls (design §6.7).

Created by the dashboard setup task: `npm create vite@latest . -- --template react-ts` inside this folder.
Built output (`dist/`) is served by FastAPI at `/` for the demo.
